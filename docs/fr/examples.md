# Bibliothèque d’exemples

La bibliothèque permet de parcourir des scènes de démonstration et de les charger dans le projet. Elle sert de point de départ graphique ; inspectez et enregistrez le projet après le chargement.

## Parcourir le catalogue

1. Choisissez **Exemples → Bibliothèque d’exemples…** (`Ctrl+Shift+E`).
2. Parcourez la liste groupée par catégorie.
3. Cliquez sur un exemple. Le panneau de droite affiche son titre, sa dimension, son niveau, sa description et ses mots-clés.
4. Cliquez sur **Charger** pour poursuivre ou **Cancel** pour fermer sans sélectionner d’exemple.

## Choisir comment charger

Une seconde boîte propose les actions suivantes :

- **Remplacer** : crée un projet à partir de l’exemple et remplace le projet courant. L’historique du projet antérieur n’est pas conservé.
- **Ajouter au projet** : ajoute la scène à la scène courante et conserve l’historique. Le projet courant et l’exemple doivent avoir la même dimension.
- **Annuler** : ne charge pas la scène.

Avant de choisir **Remplacer**, enregistrez le projet courant si vous souhaitez le garder. Avant **Ajouter au projet**, pensez aux noms déjà présents : des collisions peuvent empêcher une fusion correcte.

## Après le chargement

1. Vérifiez le nom du projet et sa dimension dans la barre d’état.
2. Parcourez le contenu dans **Model tree** et dans les onglets Materials, Models, Avatars, Contact et Visibility.
3. Cliquez sur **Rafraîchir la scène** dans **Visualisation 3D** pour afficher les avatars/populations de l’exemple.
4. Enregistrez le projet avec **File → Save As…** pour garder une copie de travail indépendante.

Les scènes disponibles et leurs catégories évoluent avec l’application. Les anciennes instructions de navigation par sept catégories ou les captures d’un catalogue différent peuvent ne plus correspondre au catalogue installé.
