# Modèles prédéfinis et anciens templates

L’onglet **Templates / Bibliothèque** décrit dans les anciennes versions n’est pas proposé dans l’interface LMGC90_GUI actuelle. Les anciennes procédures de cette page ne correspondent donc pas à une fonctionnalité disponible.

Pour commencer une scène à partir d’un contenu existant, utilisez **Exemples → Bibliothèque d’exemples…** (`Ctrl+Shift+E`) ; voir [Bibliothèque d’exemples](examples.md).

Pour créer un corps, utilisez les types proposés par l’onglet [Avatars](avatar_creation.md). Pour créer des corps déformables ou une maçonnerie, utilisez respectivement l’[Assistant Mesh](meshed.md) et l’[Assistant Maçonnerie](masonry.md).
