# Create and edit an avatar

The **Avatars** tab creates rigid or deformable bodies, attaches materials/models and contactors, and lists all bodies in the project.

![](../captures/avatars.png)

## Add an avatar

1. Open **Tabs → Open → Avatars** (`Ctrl+3`).
2. Choose a creation mode (disk, polygon, sphere, empty avatar, …) allowed for the project dimension.
3. Set the name and geometric parameters.
4. Assign a **model** and a **material**.
5. Add **contactors** (shape, colour, parameters).
6. Click **Add**.

Use **Update** / **Delete** on the selected row. For empty avatars, see [Empty avatar](empty_avatar.md). For contactor parameters, see [Contactors](contactors.md).

After creation, define [contact laws](contact_laws.md), [visibility](visibility.md) and [DOF](dof.md) as needed, then configure [computation](calculs.md).
