# Create a model

The **Models** tab defines models used by avatars (`Rxx2D`, `Rxx3D`, continuum elements, …).

![](../captures/models.png)

1. Open **Tabs → Open → Models** (`Ctrl+2`).
2. Enter **Name**, choose type compatible with the project dimension.
3. Set formulation options and **Add**.

Rigid models pair with `RIGID` materials; continuum models with elastic/multiphysics materials and meshed avatars.
