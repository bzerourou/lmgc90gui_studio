# Contact laws

A contact law describes the mechanical response of a contactor pair. The visibility table associates shapes and colours with a named law.

![](../captures/contacts.png)

## Create a law

1. Open **Tabs → Open → Contact** (`Ctrl+7`).
2. Enter **Name** (max five characters).
3. Select **Law type** and **Parameters**.
4. Click **Add**.

Common types include `IQS_CLB`, `IQS_CLB_g0`, `GAP_SGR_CLB`, `MAC_CZM`, `ELASTIC_WIRE`, `COUPLED_DOF`, etc.

## Edit or delete

Select a row → **Update** or **Delete**. After renaming/deleting, check **Visibility** references.

## Associate with contactors

Create the law, then open **Visibility**, set candidate/antagonist and **Alert**, click **Add**.
