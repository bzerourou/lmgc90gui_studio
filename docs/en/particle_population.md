# Particle populations (technical reference)

This chapter is a **technical reference** for particle population structures used by the granulometry tools and the pre-processing pipeline. It is not a step-by-step GUI tutorial.

For the interactive workflow, see [Granulometry and populations](granulometry.md).

Populations group generated grains, container walls and optional metadata (size law, seeds, group names). They are materialised into avatars and contactors when the model script / DATBOX is produced. Keep visibility laws consistent with the contactor colours assigned during generation.
